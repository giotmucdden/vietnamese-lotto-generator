# Vietnamese Lotto Card Generator

Generate 30 Vietnamese lotto cards (15 sets of 2) with decorative lion frame.

## Features
- 30 cards total (15 sets of 2 cards each)
- All 90 numbers (1-90) distributed across each set
- Exactly 5 numbers per row in 9x9 grid
- Column-based distribution
- 15 different color schemes
- Custom text: "LÔ TÔ" and "TY Family"

## Requirements
```bash
pip install Pillow
```

## Usage
1. Place your lion frame image as `lion_frame_APPROVED_FINAL.png`
2. Run: `python3 generate_lotto_cards.py`
3. Find cards in `output/` directory
